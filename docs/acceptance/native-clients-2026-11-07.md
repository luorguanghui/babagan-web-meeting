# Windows / Android 客户端与主页主题验收

前一阶段原生共享修复通过 PR #24 合并至 main，合并提交 641ae7c。客户端、更新器与同人主题在独立分支开发。

## 界面与功能

- 新主页保留网页、Windows 浏览器共享组件、Windows完整客户端、Android客户端四个清晰入口。会议信息架构、网格与响应式布局保留，只换品牌/少量皮肤。
- 用户明确以橙色为主，并拒绝深棕/暗色首页。最终营销页固定明亮白与鲜橙，原创新Q版西格莉卡角色作主页视觉；会议只用小头像。320/390/1440宽度、中英文与系统深色模式检查无横向溢出，Lighthouse无障碍/最佳实践均100。
- Windows独立WinForms/WebView2窗口，保留已验收的Node/FFmpeg DXGI→认证HTTP→独立帧线程。最低WebView2版本156；缺失或不兼容才下载固定Microsoft签名运行时，现有Node/FFmpeg直接复用。
- Android使用MediaProjection前台服务和本机WebRTC桥接返回网页MediaStream，沿用原会议授权与P2P/TURN/Cloudflare/LiveKit传输。首版最高实际30fps，暂无系统声音，会议麦克风由独立前台服务维持。
- 更新清单与发布清单均使用固定RSA-3072公钥、SHA-256验证；APK另验包名、版本和同一签名者。已加入会议/采集中推迟大包下载与版本切换；进入会议取消下载，空闲重试。Windows保留旧版本，启动健康失败回滚；Android遵循系统安装确认。启动/回前台/周期检查，网页界面在重新加载时更新，不会会中强制刷新。
- Windows安装器未取得受信任代码签名证书，首次SmartScreen提示仍可能出现；没有更改系统保护或导入自签根证书。AndroidAPK使用既有稳定证书签名，更新清单签名与OS发布者签名是不同机制。

## 大范围移动测试

只生成测试内容，没有采集私人桌面或启动游戏。4096×2304细字/图表/网格画布以120Hz裁出1920×1080视口，再用生产帧选择器取实际60Hz样本。横移1200px/s、斜移1680/960px/s、滚动2160px/s，每15秒硬切/翻转，包含遮挡、最小化与恢复。

源生成独立基线210.24fps，60个完整帧哈希均不同，排除生成器限速和重复帧。实际WebView2 156.0.4314.58、AV1、配置码率上限10Mbps：

- 90秒无截图对照：输入59.989、编码59.977、解码60.119fps；实际平均8.088Mbps。全程1920×1080，零丢包/页面/观察错误。逐秒最低编码约57.94、解码约52.93；切换时接收存在短暂波动，不能宣称任意场景逐秒恒定60fps。
- 300秒持续对照：编码59.986、解码59.959fps，实际平均8.023Mbps，目标平均6.169Mbps，可用估值10Mbps。同类横移四轮的实际码率8.697→8.167→8.349→8.343Mbps，目标6.526→6.364→6.296→6.419Mbps，没有持续下滑；QP首轮后稳定。
- 实际接收PNG的细字、边缘和网格仍可辨，未见大面积色块。PNG导出会短暂阻塞渲染，性能结论取无截图运行，视觉证据取同源另一次运行。配置值不会因观看者网络良好而自动抬高；300秒测试的逐采样实际发送峰值为10.401Mbps，编码器配置上限并非逐秒严格流量整形，也不等于固定线速。真实网络和硬件仍需各自验收。

## Android设备验收边界

宿主未开启CPU虚拟化。Emulator37.2.13及官方35.6.11在持有进程等待/软件模式与TCG opt-in下均于Android启动前以0xC0000005退出。用户决定由其进行真机测试；没有宣称MediaProjection、跨端视频或后台麦克风设备实测已通过。

按用户要求，SDK管理器已卸载模拟器、API35镜像、专用AVD。独立旧版、归档和日志在永久删除被自动审批拒绝后改为移入回收站；保留构建SDK、Gradle和ADB。未改BIOS、系统功能或安全设置。手机测试步骤见 docs/runbooks/android-client-testing.md。
