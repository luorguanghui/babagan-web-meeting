# 会议页布局验收（2026-10-14）

本次从 GitHub main 的 `ebcdc9ce72bdffe64f1f44b4c2bf56e259bc6357` 开始，保留现有配色、导航和媒体流程。

- 桌面无共享时：768px 最大宽度、300px 高的居中空态。
- 普通共享：舞台最大宽度 1440px，默认高度 68dvh；空间被提示占用时可收缩，极短窗口允许滚动。
- 桌面操作栏：麦克风、音量、共享、更多和离开集中在同一个居中操作栏。
- 手机横向共享按比例展示；竖向源保留高度限制。音量浮层跟随操作栏定位。
- 原生全屏：共享区域覆盖整个视口，不沿用普通舞台的最大尺寸。
- 连接状态：首次连接等待和失败不再沿用重连控制器默认的 Connected 状态。

本地验证使用 `apps/web/qa/preview.html` 的隔离场景，媒体和成员均为测试数据，不是真实会议。检查了 2556×1308、1920×1080、1366×768、390×844，以及 800×600 加 180px 提示区的场景；未发现横向溢出。短窗口中舞台位于提示区下方，音量浮层保持可见。设置侧面板和原生全屏入口也已检查。

连接状态新增两条回归测试，确认先失败、修复后通过。最终 lint、typecheck、897 项测试和生产构建通过。真实入会连接的服务器基地址修正后已由使用者验证正常；这些布局场景不代替多人音视频质量测试。
