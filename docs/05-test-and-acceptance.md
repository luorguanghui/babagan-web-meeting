# 测试与验收计划

## 1. 测试环境

- 目标服务器或与其规格一致的 2 核 2 GiB Debian 环境。
- Windows 10 与 Windows 11。
- 测试时最新稳定版 Chrome 和 Edge。
- 至少 5 台独立终端或 5 个独立浏览器环境，分布在两个以上公网网络。
- 可控制丢包、延迟和带宽的网络模拟工具。

正式验收必须使用真实服务器公网路径，不得仅在 localhost 或同一局域网完成。

## 2. 自动化测试层次

### 2.1 单元测试

- 会议状态机和 24 小时/10 分钟/30 秒时间边界。
- 密码哈希、会话 Token 哈希和常量时间比较。
- 昵称、会议名、密码和请求体校验。
- 单会议、5 人限制和共享锁的并发竞争。
- LiveKit 权限映射和错误码转换。

### 2.2 API 集成测试

- 使用临时 SQLite 和可替换 LiveKit Server API。
- 覆盖创建、加入、满员、结束、过期、移除、共享授权和撤销。
- 并发执行多个加入请求，验证“在线身份 + 未过期预留”的并集始终不超过 5。
- 验证 LiveKit Webhook 签名、重放幂等、加入预留清理和离开状态同步。
- 验证 5 分钟 JWT 到期后的完整重连刷新，以及被移除成员无法刷新并会被 Webhook 再次移除。
- 验证 Cookie、Origin、CORS、速率限制和错误响应不泄密。
- 验证进程重启后的会议恢复和过期清理。

### 2.3 浏览器 E2E

- Chrome 和 Edge 各执行完整主持人/参会者流程。
- 使用浏览器提供的虚拟音频设备执行自动化基础路径。
- 屏幕选择、系统声音和权限弹窗由人工测试补足。

## 4. 媒体质量测试

### 4.1 语音

- 采集浏览器 WebRTC 统计中的 RTT、抖动、丢包、concealed samples 和可用码率。
- 正常网络目标：端到端主观延迟低于 300ms，无持续断音。
- 5 人同时说话时不发生服务器 CPU 饱和或音频轨道丢失。
- 使用扬声器时验证回声消除；正式会议仍建议耳机。

### 4.2 屏幕

- 标准模式验证 1920×1080、目标 30fps，文字在 100% 显示比例下可辨认。
- 高动态模式验证目标 60fps，并共享包含运动内容的窗口。
- 验证标签页音频和 Windows 可用的系统音频路径。
- 未返回音频轨道时必须显示正确指导，不能静默失败。
- 四名观看者同时订阅时不出现长期黑屏或宽高比错误。

## 5. 弱网和回退

| 场景 | 条件 | 预期 |
|---|---|---|
| 限制上行 | 共享端 6 Mbps | 屏幕自动降级，语音持续 |
| 丢包 | 5% 随机丢包 | 语音可理解，UI 显示质量下降 |
| 高延迟 | 150ms 单向 | 不中断，连接质量正确反映 |
| 短断网 | 10 秒 | 自动重连并恢复身份/订阅 |
| 超过保留期 | 断网 >30 秒 | 以新连接重新加入 |
| 禁止媒体 UDP 范围 | 仅 UDP 443 可用 | 经 TURN/UDP 建立连接 |
| 禁止全部 UDP | TCP 7881 可用 | 使用 RTC/TCP 回退或明确失败提示 |

## 6. 负载与稳定性

标准负载模型：1 个房间、5 人、5 路麦克风、1 路 1080p60 屏幕及屏幕音频、4 名订阅者。

通过标准：

- 连续 2 小时无非预期参与者断线。
- CPU 持续低于 80%，短峰不超过 95%。
- 内存不超过 1.8 GiB，首尾 30 分钟平均内存差异不超过 150 MiB。
- 无 OOM、容器重启、持续磁盘增长或大量 5xx。
- 出口带宽未触及 200 Mbps 峰值且没有服务器侧持续丢包。

## 7. 安全测试

- 暴力尝试管理密码和会议密码触发速率限制。
- 修改 Cookie、会议 ID、身份 ID 和 LiveKit Token 不得越权。
- 普通成员不能发布摄像头、数据或未授权屏幕轨道。
- CSRF、跨来源请求、XSS、SQL 注入和超大请求体被阻止。
- 错误页、日志和监控不包含密码、Token、Cookie、API Secret 或数据库内容。
- 外部端口扫描只看到批准的端口。
- TLS 配置通过现代浏览器和自动化 TLS 检查。

## 8. 发布门禁

以下任一条件失败即不得发布：

- FR-001 至 FR-014 存在未通过项。
- Chrome 或 Edge 的核心流程失败。
- 5 人 1080p60 负载或两小时稳定性失败。
- 出现高危安全问题、权限提升或敏感信息泄露。
- 部署、备份恢复或回滚未在目标环境演练。

测试报告记录构建版本、浏览器版本、网络条件、服务器指标、失败证据和最终批准人，不记录会议媒体。
