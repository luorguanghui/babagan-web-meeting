# 产品需求规格（PRD）

## 1. 产品目标

提供一个部署在自有服务器上的极简网页会议工具，让最多 5 名参与者通过临时链接加入同一个会议。所有人可自由开麦，主持人可指定其中一人共享 Windows 电脑屏幕与电脑声音。

成功标准是语音低延迟、屏幕文字清晰、动态内容流畅、复杂网络可回退连接，并且在现有 2 核 2 GiB 服务器上连续稳定运行。

## 2. 用户角色

### 2.1 主持人

- 使用固定管理密码创建会议。
- 设置会议名称和可选会议密码。
- 获取并复制普通参会链接。
- 指定或撤销屏幕共享者。
- 移除成员或结束会议。
- 与其他成员相同，可以自由开麦和静音。

### 2.2 参会者

- 通过临时链接、昵称和可选会议密码加入。
- 默认静音入会，之后可自由开麦或静音。
- 观看共享屏幕、收听共享电脑声音和其他成员语音。
- 获主持人授权后，可共享屏幕和电脑声音。
- 可切换自己的麦克风、扬声器，并分别调节接收的共享电脑音频和通话音频；通话音频指全部远端成员的麦克风音频。

## 3. 核心用户流程

### 3.1 创建会议

1. 主持人打开创建页。
2. 输入管理密码、会议名称和可选会议密码。
3. 系统确认当前没有其他活动会议。
4. 创建有效期为 24 小时的随机会议标识。
5. 建立主持人安全会话并返回普通参会链接。

### 3.2 加入会议

1. 用户打开参会链接。
2. 页面检查操作系统、浏览器和媒体能力。
3. 用户输入昵称和会议密码，选择麦克风与扬声器。
4. 用户完成麦克风测试并以静音状态加入。
5. 系统显示成员、开麦状态、共享画面和连接质量。

### 3.3 屏幕共享

1. 主持人选定一个成员并授予共享权限。
2. 该成员选择整个屏幕、窗口或标签页，并选择是否包含电脑声音。
3. 质量预设三档：弱网 720p/30fps、标准 1080p/30fps（默认）、高动态 1080p/60fps。
4. 屏幕画面优先通过参与者之间的网络直连传输，网络不支持时系统自动改用服务器中继；用户无感知，画面在两种方式间自动切换。
5. 共享停止、成员断线或主持人撤销后，共享锁自动释放。

## 4. 功能需求

| 编号 | 需求 | 验收要点 |
|---|---|---|
| FR-001 | 管理密码创建会议 | 密码错误不得创建；同一时间只能有一个活动会议 |
| FR-002 | 临时随机会议链接 | 标识不可枚举；创建后 24 小时过期 |
| FR-003 | 可选会议密码 | 使用安全哈希保存；错误提示不泄露会议状态细节 |
| FR-004 | 昵称加入 | 1–40 个可显示字符；服务端生成唯一身份 ID |
| FR-005 | 最多 5 人 | 并发竞争时仍不得超过 5 人 |
| FR-006 | 默认静音入会 | 入会后任何成员可自由开麦或静音 |
| FR-007 | 音频设备与接收音量 | 可选择麦克风、扬声器并测试麦克风；接收端可分别调节共享音频和全部远端麦克风的聚合通话音量 |
| FR-008 | 单人共享锁 | 任意时刻最多一个屏幕共享者 |
| FR-009 | 分享电脑声音 | 支持 Windows Chrome/Edge 可用的屏幕或标签页音频 |
| FR-010 | 720p/1080p 30/60 | 三档质量预设（720p30、1080p30 默认、1080p60），网络波动时自适应降级 |
| FR-011 | 主持人管理 | 可授权共享、撤销共享、移除成员和结束会议 |
| FR-012 | 自动重连 | 短暂断网时显示状态并在 30 秒身份保留期内重连 |
| FR-013 | 空房回收 | 全部离开后保留 10 分钟，之后自动结束 |
| FR-014 | 不保存媒体 | 不录音、不录像、不保存屏幕帧 |
| FR-015 | 屏幕传输优先直连 | 屏幕画面优先经参与者间直连传输，不依赖服务器带宽；无法直连时依次回退 coturn TURN 中继、LiveKit SFU，画面不中断 |
| FR-016 | 屏幕音画同步 | 共享屏幕的电脑声音与画面必须保持同步，不允许因传输路径不同出现明显音画错位 |

## 5. 非功能需求

### 5.1 性能与质量

- 正常网络下提交入会后 5 秒内进入房间。
- 正常网络下语音端到端延迟目标低于 300ms。
- 语音优先级高于屏幕画质；弱网时先降低视频码率或分辨率。
- 屏幕画面传输不依赖服务器带宽的稳定性：直连可用时，服务器带宽波动不得影响接收画面（直连传输由参与者间链路承载）。
- 屏幕共享建立：用户点击共享后 3 秒内开始尝试直连，直连不可用时自动回退中继且画面中断不超过 2 秒。
- 5 人、单路 1080p60 时服务器 CPU 持续低于 80%，内存不超过 1.8 GiB。
- 连续会议 2 小时无非预期断线，无明显持续性内存增长。

### 5.2 可用性

- API、LiveKit 或网络错误必须显示可行动的中文提示。
- 权限拒绝时说明如何在 Chrome/Edge 中重新授权。
- 满员、密码错误、会议结束、浏览器不兼容使用不同错误信息。
- UI 在 1366×768 及更高桌面分辨率下完整可用。

### 5.3 兼容性

- 正式验收：Windows 10/11 最新稳定版 Chrome 和 Edge。
- 手机浏览器：允许观看共享和语音交流，不验收屏幕共享。
- 不纳入首版：macOS、Firefox、Safari、Linux 桌面浏览器。

## 6. 生命周期规则

- 会议创建后 24 小时到期。
- 主持人结束会议后立即禁止新连接并移除现有成员。
- 空房 10 分钟后结束。
- 参与者临时断线保留身份 30 秒。
- 会议结束后删除会议密码哈希和主持人会话；审计日志按安全文档保留。

## 7. 明确不做

- 摄像头视频、会议录制、直播、转码或媒体混流。
- 文字聊天、文件传输、白板、表情、举手、字幕和翻译。
- 用户注册、第三方登录、通讯录、日历和邮件邀请。
- 多个并发房间、超过 5 人或跨区域部署。
- 服务端 AI 降噪、背景处理或内容分析。

## 8. 产品术语

- **活动会议**：处于可加入、进行中或 10 分钟空房保留期的会议。
- **主持人管理密码**：服务器级固定密码，只用于建立主持人会话。
- **会议密码**：每场会议可选的参会密码。
- **共享锁**：保证同时只有一个屏幕共享者的服务端状态。
- **SFU**：只选择性转发媒体轨道、不进行视频合成的媒体服务器。
- **P2P 直连**：屏幕画面直接在参与者的设备之间传输，不经过服务器。
- **自动回退**：直连不可用时系统自动改经 coturn TURN 中继，仍失败则回退 LiveKit SFU，用户无需手动切换。
- **TURN 中继**：coturn 提供的 relay 候选，供无法直连的观看者仍经 P2P 通道收发屏幕媒体。
