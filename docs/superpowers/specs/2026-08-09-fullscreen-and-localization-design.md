# 全屏控件与双语界面设计

## 目标

改善共享屏幕观看体验，并为整个 Web 客户端提供简体中文和英语界面：

- 全屏按钮改为紧凑的图形按钮，不再以大块文字遮挡画面。
- 进入全屏后隐藏页面内的全屏按钮，用户通过浏览器标准的 `Esc` 操作退出。
- 首次访问自动跟随浏览器语言，支持用户随时切换，并记住手动选择。
- 创建、加入、设备检查、会议室、主持人操作、连接状态和屏幕共享提示使用同一套语言。

## 方案选择

采用项目内轻量国际化层，不引入第三方国际化依赖。当前只有两个语言包，项目规模较小；使用类型安全的词典和 React 上下文可以保持构建体积和实现复杂度可控。若未来增加复数规则、日期格式或大量语言，再评估迁移到成熟国际化库。

## 全屏控件

`ScreenStage` 继续对共享画面容器调用标准 Fullscreen API，不改变媒体轨道和播放逻辑。

- 使用约 36 × 36 像素的按钮，内容为四角扩展 SVG 图标。
- 按钮保留可翻译的 `aria-label` 和 `title`，键盘焦点样式继续可见。
- 非全屏状态下，按钮位于共享画面右上角，使用半透明深色背景。
- `.screen-stage:fullscreen .screen-stage-fullscreen` 隐藏按钮，避免任何页面控件长期覆盖全屏内容。
- 全屏退出依赖浏览器标准 `Esc` 行为，不另加常驻退出按钮。
- Fullscreen API 不可用或请求被拒绝时保持当前非全屏画面，不显示阻塞错误。

## 国际化架构

新增一个独立的国际化模块，职责包括语言解析、词典读取、上下文状态和持久化。

### 语言模型

仅支持：

- `zh-CN`：简体中文
- `en`：英语

首次加载时按以下优先级确定语言：

1. 读取 `localStorage` 中有效的用户选择。
2. 检查 `navigator.languages`，任一首选语言以 `zh` 开头时使用 `zh-CN`。
3. 其他情况使用 `en`。

用户手动切换后，将值写入 `localStorage`。每次语言变化同步设置 `document.documentElement.lang`。存储不可用时仍在当前页面内完成切换，不中断应用。

### 组件边界

- `LanguageProvider`：在路由外层保存当前语言，向子组件提供翻译函数和切换方法。
- `LanguageSelector`：全局紧凑选择器，提供“简体中文”和“English”两个选项。
- 翻译词典：使用稳定键名保存两种语言的文案；带参文案通过参数函数生成，避免在组件内拼接不可翻译的句子。
- 页面和组件只消费翻译接口，不直接读取浏览器语言或存储。

语言选择器显示在应用右上区域：创建和加入页面位于面板上方；会议室位于页面标题区域。它不属于共享画面容器，因此进入共享画面全屏时不会覆盖视频。

## 文案覆盖范围

以下用户可见内容必须双语化：

- 创建会议表单、验证、创建结果和复制状态。
- 加入大厅、浏览器兼容性提示和加入错误。
- 麦克风预览、音量计、扬声器测试及权限提示。
- 会议连接和重连状态。
- 麦克风、扬声器、画质、屏幕共享和离开会议控件。
- 参会者列表及无障碍描述。
- 主持人授权共享、撤销共享、踢出成员和结束会议操作。
- 屏幕共享空状态、全屏按钮和系统音频回声保护提示。
- 应用级错误边界及支持编号标签。
- `aria-label`、`title`、状态文本和确认对话框。

API 返回的已知错误根据错误代码映射为本地文案；未知错误使用当前语言的通用失败消息。中文模式不直接显示无法控制语言的英文服务端消息。关联 ID 仍保留，便于排查。

## 状态与数据流

语言切换只影响界面文案，不重建会议连接、媒体轨道或屏幕共享控制器。组件重渲染后使用新语言，输入内容、会议状态和已获得的媒体权限保持不变。

国际化上下文位于 `BrowserRouter` 外层或与其同级的应用根部，使创建、加入和会议路由共享同一个选择。错误边界也能访问当前语言，确保崩溃界面一致。

## 可访问性与响应式要求

- 图标按钮必须具有可见的键盘焦点和可翻译的无障碍名称。
- 语言选择器使用关联标签，不能只依赖国旗或图标表达语言。
- 切换语言后更新 HTML `lang`，帮助屏幕阅读器使用正确发音。
- 语言选择器在窄屏不遮挡标题或会议控制；允许换行到标题上方。
- 尊重现有的减少动态效果设置，不新增必须依赖动画才能理解的状态。

## 测试策略

使用现有 Vitest 和 Testing Library 测试真实用户行为：

- 无保存值时根据 `navigator.languages` 选择中文或英语。
- 有保存值时优先采用保存语言。
- 手动切换后页面文案、HTML `lang` 和存储值同步更新。
- 存储抛错时切换仍在当前会话生效。
- 创建、加入和会议室各验证一个代表性中文流程，防止语言上下文只覆盖部分路由。
- 带成员名称和连接状态的动态文案使用当前语言生成。
- 全屏按钮以 SVG 图标呈现，仍能触发 `requestFullscreen`，并通过全屏 CSS 状态隐藏。
- 保留现有英文测试或显式指定英语，使旧行为仍受回归保护。

完成实现后运行专项测试、全部测试、类型检查、lint 和生产构建；部署仍使用仅替换 Web 容器的热更新方式。

## 非目标

- 本次不增加繁体中文或其他语言。
- 不翻译服务器日志、开发者错误或 LiveKit 内部状态值。
- 不改变 WebRTC、媒体编码、码率、播放延迟或服务器部署架构。
- 不实现自定义全屏退出手势或覆盖浏览器原生全屏提示。
