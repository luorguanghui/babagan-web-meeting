# Sunny shared-screen fixture

`sunny-shared-screen.png` is an AI-generated raster matching the selected Sunny companions visual concept: cream background, orange sun, green hills and daisies, with “SHARED SCREEN / DEMO” and “一起创造一点好玩的”.

It is used only by `/qa/preview.html?design=sunny`. The fixture draws the complete image with contain sizing into an isolated canvas stream. It does not capture any screen, connect to a meeting, or replace production shared media. Vite's production entry does not import the QA page or this asset.
