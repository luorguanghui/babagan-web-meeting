# Sigrika fan theme

Original artwork generated with the built-in image_gen tool for this project, using official Sigrika character images solely as identity references. No fan artist image was copied into the application.

Official references: https://wutheringwaves.kurogames.com/en/main/news/detail/4410 and https://wutheringwaves.kurogames.com/en/main/news/detail/4393 .

Hero prompt: an original cheerful 2.5-head-tall chibi Sigrika, orange fluffy segmented braids and thin face-framing braids, white headscarf with simplified silver wing ornaments and purple ribbon accents, white/lavender modest outfit. Hugging a cream laptop and waving; warm orange and apricot dominate; clean rounded linework and soft cel shading; transparent background; no words or logos.

Avatar prompt: same original chibi identity and friendly teal/lilac eyes; head-and-shoulders in a pale-apricot rounded-square tile, orange hair dominant, simplified for small icons; transparent outside, no words or badges.

Files: sigrika-hero.png, sigrika-avatar.png; favicon-32.png and apple-touch-icon.png are deterministic resized outputs. Windows ICO and Android launcher assets derive from the same avatar. Website footer labels the design as unofficial fan art, without implying endorsement.
