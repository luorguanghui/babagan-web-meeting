# Babagan Windows icon

Current `babagan.ico` is derived from the original Sigrika chibi fan-art avatar at `apps/web/public/theme/sigrika-avatar.png`. Orange and white match the homepage. The original olive icon master is retained for provenance only.

Nine ICO sizes (16–256px) are produced by `scripts/native-icon-builder.cs`, which performs only scaling/encoding. The browser icon and Apple touch icon use the same artwork. Prompts and source references are recorded in `apps/web/public/theme/README.md`.
